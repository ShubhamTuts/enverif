# Governance

Enverif uses a maintainer-led open-source model. Maintainers steward the security boundary, release process and core interfaces. Contributors can earn broader review and merge responsibility through sustained, high-quality work.

Core contracts—agent state, capability/risk semantics, workspace isolation, plugin manifests and skill metadata—change through reviewed proposals because downstream extensions depend on them. Translation, documentation, skills and isolated connector improvements may move faster when they preserve those contracts.
