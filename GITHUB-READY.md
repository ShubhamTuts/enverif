# Enverif — GitHub-ready application repository

This repository contains the Enverif Laravel application source for GitHub.

Included:

- Laravel 13 application source and migrations;
- durable agentic chat, agents, workflows, schedules, leads and campaigns;
- first-party Codefreex plugins plus external plugin extension points;
- skills and MCP extension layers;
- shared-hosting / Hostinger / cPanel / Plesk runtime and Apache routing;
- Markdown operator + developer documentation under `docs/`;
- `.github/` CI and tag-driven release workflows;
- tests and release verifier.

Not included in the application repository:

- `websites/enverif.com` and `websites/docs.enverif.com` marketing/docs static sites (packaged separately when needed for GitHub Pages).

## Dependency boundary

This source repository intentionally does not vendor Composer/npm dependencies until lockfiles are generated by CI.

Before creating a production tag:

1. run the **Generate dependency lockfiles** GitHub workflow (when available);
2. confirm the MySQL/Redis/database-runtime Laravel matrix passes;
3. create the version tag matching `VERSION`.

The tag-driven Release workflow then creates the shared-hosting package containing production `vendor/` and compiled assets.
